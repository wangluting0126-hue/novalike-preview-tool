# Novalike Preview Tool

前端预览工具：用于叠加 Novalike 点赞特效（Sticker / Animation）到竖版视频并导出预览视频。

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

构建产物输出在 `dist/`。

## 部署到 GitHub Pages（GitHub Actions）

本项目已内置 GitHub Pages 工作流：`.github/workflows/deploy-pages.yml`。

部署步骤：
1. 在 GitHub 新建一个仓库（建议同名：`novalike-preview`）
2. 将本地代码推送到 `main` 分支
3. 在仓库 Settings → Pages 中，将 **Source** 设为 **GitHub Actions**
4. 之后每次 push 到 `main` 都会自动构建并发布到 Pages

> 说明：`vite.config.ts` 已设置 `base: './'`，避免 Pages 子路径导致静态资源 404。
